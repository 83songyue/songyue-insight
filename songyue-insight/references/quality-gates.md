# 洞察质量门

洞察不是高频现象、社会趋势或漂亮文案，而是对可观察行为背后原因的解释。它尤其要说明：为什么最容易得到的表面结论还不够。

形成候选解释和终稿前依次过以下六道门。任何一道关键门不通过，都应降级为待验证假设或停止。

## 一、事实门：有没有人在做什么

检查：

- 是否至少有具体行为、选择、放弃、替代或复购信号；
- 是否知道行为发生在什么场景和阶段；
- 是否区分消费者原话、观察事实、研究者解释；
- 是否把“年轻人压力大”“健康意识提升”等社会背景当成了行为证据。

只有态度词、趋势词、人口标签或行业数据，不通过事实门。

## 二、解释门：到底多解释了什么

先写最容易得到的表面解释，再回答：

- 它解释不了哪个事实或矛盾？
- 新解释是否同时覆盖主要事实和反例？
- 是否还有一个更简单的解释同样成立？
- 什么新证据会推翻这个解释？

好的洞察不是“往深处说”，而是比表面结论多解释一件重要的事。

从一个选择跳到“消费者真正买的只有某种东西”，需要额外证据。不能因发现信任动机就排除口味，也不能把消费者用来判断产品的线索，写成该产品真实属性的证明。

常见矛盾：

- 说想要更多，得到更多后反而更难行动；
- 因一个理由第一次买，却因另一个理由复购；
- 口头重视某价值，实际选择却被时间、麻烦或关系左右；
- 想得到一种好处，同时回避它的代价；
- 同一行为在不同角色眼中意义不同。

## 三、样本门：它能代表谁

检查：

- 是否从单个平台、几条高赞内容或一个极端故事外推整个人群；
- 购买者、使用者、付款者是否被混在一起；
- 是否把资深用户当普通用户，把愿意发帖的人当沉默用户；
- 是否说明人群、场景、阶段和当前不能代表谁；
- 相反证据是噪音，还是说明洞察只在一部分人中成立。

边界不是免责声明，而是洞察本身的一部分。没有边界的“人性”通常只是泛化。

## 四、任务门：它解释了品类中的什么选择

在内部区分两件事，不靠策略篇幅证明洞察有用：

### 洞察可信度

现有事实是否支持这个解释？是已证实、较强解释、待验证假设，还是只有灵感？

### 品类解释力

- 它说明了这个品类中一个重要行为为什么发生，还是仅重复这个行为？
- 一条跨品类成立的判断，是否通过当前品类的证据解释了具体选择？跨品类可用本身不是缺点，缺少当前问题的解释力才是。
- 是否把礼赠等局部场景抬成整个品类的购买理由？不能覆盖全体消费者不等于无效，但要分清主洞察与局部补充。
- 多条洞察是否各自解释不同的行为、矛盾或原因？同一动机的换词和经营后果不算新洞察。

洞察成立不以“已经推导出品牌策略”为条件。仅在用户要求策略延展时，再检查品牌资格与营销可用性；不能为让品牌有话可说而改变消费者解释。

## 五、表达门：朴实而锐利

终稿前做四次删改：

1. 每条洞察优先用一句话表达一个判断，不把多层推导和经营后果串成一个长句；
2. 把抽象词换成动作、处境和选择；
3. 删除故意押韵、价值升华和“不是 A 而是 B”的空反转；
4. 补回明确对象与场景，防止把局部判断写成普遍人性。

自检：

- 一个聪明的普通人能否一次读懂？
- 去掉“渴望、追求、重构、疗愈、情绪价值”后，解释力还在不在？
- 它是不是只比常识更会写，而没有比常识多解释事实？
- 让人觉得“对，我就是这样”的同时，证据能否回答“凭什么这样判断”？

朴实不等于浅；锐利不等于金句。表达效果不能替代真实性。

简短是表达偏好，不是硬字数考核。洞察句尽量短，正文仍要有具体事实和关键推导，让人看懂判断是怎么来的。删除策略篇幅，不等于删除解释。

开放式挖掘以至少两个独立洞察为目标，充分时三个、四个均可，不设固定总数。先确认研究覆盖，再按证据筛选；若确实不足，说明缺口，不用弱例、同义改写或补充判断填数量。

## 六、停止门：现在该下结论吗

| 证据状态 | 处理 |
|---|---|
| 多类事实相互支持，反证已解释，边界明确 | 可以输出有置信边界的洞察 |
| 解释有价值，但缺访谈、行为或业务数据 | 明确标为待验证假设，并给最小验证动作 |
| 只有宏观趋势、高频词或单平台态度 | 只输出已确认现象，不生成洞察 |
| 关键角色未分、信源冲突、关键平台不可达 | 说明缺口，缩小研究或停止 |
| 句子很漂亮，但找不到事实 | 删除句子，回到证据 |

停止时使用：

> 目前能确认的是现象，还不足以形成消费者洞察。缺少的是……

补证建议只给最小动作，例如补 8–12 次目标情境访谈、核对退换/复购数据、增加购买者与使用者对照，或补一个行为更接近的信源。不要用一份长报告掩盖“不知道”。

## 七、伪洞察快速识别

出现以下特征时先否决，再要求证据：

- **背景冒充洞察**：时代变了、生活更快、年轻人更焦虑；
- **高频冒充因果**：大家都说松弛感，所以购买就是为了松弛；
- **金句冒充判断**：有反差、有押韵，却没有对象、场景和事实；
- **创意倒装**：先想到一个好概念，再把它写成消费者内心；
- **策略倒装**：品牌想占某个价值，就宣称消费者正在追求它；
- **共识升华**：妈妈辛苦、家人重要、健康重要，却没有新解释；
- **平台全貌错觉**：把真实帖子等同于全部真实生活；
- **强行普遍化**：用“人们、年轻人、女性消费者”抹掉差异。

## 八、终稿复核顺序

1. 圈出事实句，确认它们不是解释。
2. 写出表面解释以及它解释不了的事实。
3. 比较竞争解释和可推翻证据。
4. 明确人群、场景、阶段和角色边界。
5. 分别判断可信度与品类解释力，区分主洞察和局部补充。
6. 检查研究是否充分、多条判断是否独立，不凑数量。
7. 每条保留“现象 → 关键推导 → 洞察”，洞察句优先简短，正文解释充分。
8. 检查是否擅自扩成策略报告；没有必要的启发就不加结尾。
9. 任一候选的关键环节断裂，单独降级或停止；对证据充分的其他判断予以保留。
