# 匿名案例校准卡

这些案例只用于当前问题完成独立推导后的结构校准。不要复制案例结论，不要因为新品类“看起来相似”就套用旧洞察。

卡片中的“营销选择”用于回看历史案例的后续应用，不是默认输出模板或洞察成立的必要条件。普通洞察任务重点校准事实、解释和边界，不照搬卡片展开品牌策略。

证据状态分为：`已观察的公开机制`、`历史方案推导`、`待验证假设`、`反例`。表达完整不等于证据充分。

## 强例与待验证强假设

### 案例 1：收藏得更多，决定得更少

- **案例类型**：育儿知识 / 待验证强假设
- **证据状态**：待验证假设
- **可观察事实**：一些照顾者会收藏大量育儿方法；部分人收藏增加后并未更快行动，反而更担心选错。
- **最容易得到的表面解释**：她们越来越专业，需要更多系统化知识。
- **表面解释漏掉了什么**：如果缺的是知识，收藏增加本应让行动更容易，为什么反而更难决定？
- **洞察或待验证假设**：对这部分收藏很多却迟迟不行动的人，缺的可能不是更多方法，而是判断眼前该先做哪一件事的确定感。
- **营销选择**：减少答案堆叠，帮助用户缩小选择，并说明在什么情况下先做什么就够了。
- **为什么成立或值得验证**：它解释了“信息更多、行动更少”的反常行为，也能导出不同的产品与内容选择。
- **适用边界**：只针对高收藏、低行动且害怕选错的人；需用访谈、行为记录和产品数据验证，不能代表所有照顾者。

### 案例 2：标签先替动作打了分

- **案例类型**：体育传播 / 认知预设
- **证据状态**：已观察的公开机制
- **可观察事实**：观众看到一组被处理成男性运动员形象的精彩动作时给予赞叹；揭示后发现原动作来自女性运动员。
- **最容易得到的表面解释**：某类比赛受到的关注少，所以观众不知道它同样精彩。
- **表面解释漏掉了什么**：为什么同一个动作只换了身份标签，评价就可能不同？
- **洞察或待验证假设**：对部分观众来说，是否精彩不只来自动作本身，既有标签会提前参与判断。
- **营销选择**：不要只劝观众“改变偏见”；先暂时拿掉标签，让他们先按动作做判断，再揭示标签如何影响了自己。
- **为什么成立或值得验证**：传播机制让观众经历了自己的判断变化，而不是只听品牌宣讲正确价值。
- **适用边界**：案例证明这种预设可以被创意显影，不证明所有观众都持有同一偏见，也不证明关注差距只有这一个原因。

### 案例 3：用户分享的不是统计表

- **案例类型**：数字产品 / 年度回顾
- **证据状态**：已观察的公开机制
- **可观察事实**：年度听歌记录被组织成个人化故事后，许多用户愿意主动分享；普通的分钟数和歌曲排名本身并不总有同样传播力。
- **最容易得到的表面解释**：用户喜欢看到自己的音乐偏好和年度数据。
- **表面解释漏掉了什么**：一份私人统计为什么值得公开转发给别人？
- **洞察或待验证假设**：对愿意分享的人，听歌痕迹不只记录音乐偏好，也能帮他讲出“这一年的我”。
- **营销选择**：不要只做数据账单；把数据组织成用户可以认领、回忆和表达自己的叙事。
- **为什么成立或值得验证**：它解释了从查看到分享的行为变化，并把产品数据转化为用户的自我表达工具。
- **适用边界**：不意味着平台能准确推断用户每天的真实情绪；也不代表所有用户都愿意公开分享。

### 案例 4：多做一步不是赞美，是行为入口

- **案例类型**：衣物护理 / 新习惯教育
- **证据状态**：历史方案推导，待外部验证
- **可观察事实**：部分幼儿照顾者会多带衣服、反复试温、处理家具边角；洗衣时却未必知道专业护理产品与普通洗涤产品的区别，也容易选择一步完成的替代品。
- **最容易得到的表面解释**：照顾者爱家人、重视健康，因此需要更专业的清洁产品。
- **表面解释漏掉了什么**：泛泛赞美照顾者并不能解释如何让一个陌生品类进入已有洗衣流程，也无法对抗更省事的替代方案。
- **洞察或待验证假设**：对这类在照顾细节上习惯多检查一步的人，新产品必须被理解为她原有照顾动作的延伸，而不是额外增加的一堂健康课。
- **营销选择**：先把产品变成一个清楚、可执行的额外动作，再谈情感与专业价值。
- **为什么成立或值得验证**：消费者行为、品类教育和品牌动作连成一条链；“多一步”同时回答为什么做和具体怎么做。
- **适用边界**：来自历史方案推导，不能证明所有母亲或照顾者都如此；还需验证额外动作带来的麻烦是否超过专业价值。

### 案例 5：一个有时代感的词，为什么被推翻

- **案例类型**：节庆礼赠 / 洞察修正过程
- **证据状态**：历史项目内迭代假设
- **可观察事实**：初轮研究看到部分年轻人减少走亲访友，线上送达增加，于是用一个强调关系疏离的流行词解释变化。反馈指出，这个词对较年长的核心购买者缺乏共鸣，甚至令人反感；礼赠对象也不只包含亲戚。
- **最容易得到的表面解释**：年轻人正在疏远亲缘，所以礼物替代见面。
- **表面解释漏掉了什么**：减少无效见面可能源于精力、时间与相处方式变化，不等于感情消失；朋友、同事、客户等关系也无法被“亲缘疏离”解释。
- **洞察或待验证假设**：对一部分希望减少打扰、仍愿意表达牵挂的人，远程送达不是见不了面的补偿，也可能是一种主动选择的轻量关心。
- **营销选择**：放弃带代际攻击性的流行标签；从“关系断了”改为“关系仍在，但表达方式变轻”，同时覆盖更多礼赠关系。
- **为什么成立或值得验证**：它展示了反证如何缩小人群、修正动机并降低品牌风险，而不是硬保留一句看似锐利的话。
- **适用边界**：仍是项目内假设；线上送达增长不能单独证明“不打扰的关心”，需核对不同年龄、关系和送礼动机。

## 弱例

### 案例 6：社会压力万能解释

- **案例类型**：零食 / 背景冒充洞察
- **证据状态**：反例
- **可观察事实**：没有具体消费者行为，只有“工作节奏快、压力大”。
- **最容易得到的表面解释**：年轻人需要零食带来治愈。
- **表面解释漏掉了什么**：为什么选这种零食、何时吃、为什么复购或吃不完，都没有被解释。
- **洞察或待验证假设**：当前不是洞察，只是社会背景加抽象情绪词。
- **营销选择**：不应直接推出“治愈系”传播；先研究具体场景、替代品、保鲜、份量和复购。
- **为什么成立或值得验证**：该说法换成咖啡、香氛、耳机等仍然成立，无法形成品类选择。
- **适用边界**：可以作为查询背景，不能作为结论。

### 案例 7：健康意识替代购买动机

- **案例类型**：健康食品 / 趋势冒充洞察
- **证据状态**：反例
- **可观察事实**：行业报告显示健康相关关注和产品供给上升。
- **最容易得到的表面解释**：消费者越来越重视健康，所以愿意购买更健康的产品。
- **表面解释漏掉了什么**：关注不等于付钱；口味、价格、麻烦、家庭成员和持续使用可能决定真实选择。
- **洞察或待验证假设**：当前只能确认趋势，不能确认个人购买动机。
- **营销选择**：补购买、复购、放弃和替代证据，不能直接把包装写成“健康生活方式”。
- **为什么成立或值得验证**：宏观规模回答多少，不回答为什么选择这个产品。
- **适用边界**：行业趋势可作校验源，不可单独作人性解释。

### 案例 8：高赞评论代表所有人

- **案例类型**：生活方式 / 单平台外推
- **证据状态**：反例
- **可观察事实**：某平台的多篇高赞帖子和评论反复出现同一个词。
- **最容易得到的表面解释**：这一代消费者都在追求这个价值。
- **表面解释漏掉了什么**：平台选择了谁表达、什么内容被放大，研究者又选择了什么关键词；沉默者和真实购买行为均不可见。
- **洞察或待验证假设**：只能确认该平台的一种强表达信号。
- **营销选择**：补决策行为源、反向查询和其他角色样本，再决定是否形成洞察。
- **为什么成立或值得验证**：真实帖子不等于完整生活，样本多只会放大同一种偏差。
- **适用边界**：结论最多适用于当前平台、查询词和可见表达者。

### 案例 9：一句反差就是洞察

- **案例类型**：文案判断 / 金句冒充洞察
- **证据状态**：反例
- **可观察事实**：只有一句“不是需要更多选择，而是需要被选择”的漂亮表达。
- **最容易得到的表面解释**：有反差、听起来深，所以是洞察。
- **表面解释漏掉了什么**：谁在什么场景做了什么？“被选择”解释了哪个反常行为？没有答案。
- **洞察或待验证假设**：它最多是候选文案或研究假设，不是已成立洞察。
- **营销选择**：先找对应行为、对象和反证；找不到就删除，不为句子补故事。
- **为什么成立或值得验证**：表达效果不能证明真实性。
- **适用边界**：任何脱离证据的金句都应降级处理。

### 案例 10：品牌想说，所以消费者想要

- **案例类型**：品牌策略 / 策略倒装
- **证据状态**：反例
- **可观察事实**：品牌希望占据“勇敢做自己”的价值，方案因此声称消费者渴望做真实的自己。
- **最容易得到的表面解释**：品牌价值与社会情绪一致，所以洞察成立。
- **表面解释漏掉了什么**：消费者在哪个具体选择上付出了“不做自己”的代价？品牌产品又改变了什么？
- **洞察或待验证假设**：这是品牌主张，不是消费者洞察。
- **营销选择**：回到具体行为障碍，确认品牌是否有真实能力帮助，而不是用价值观倒写人性。
- **为什么成立或值得验证**：同一句话可以被大量无关品牌使用，无法解释当下选择。
- **适用边界**：价值主张可作为品牌意图，但必须另找消费者证据与品牌资格。
