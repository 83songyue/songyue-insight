# 信源路由：到哪里找什么

平台不是固定答案。先判断人群、购买角色、消费阶段和要观察的信号，再决定去哪找。

## 一、路由四问

1. **谁在生活这个问题？** 年龄、性别、城市只能作为入口，还要看到处境、任务和关系。
2. **谁在做决定？** 购买者、使用者、付款者、影响者可能不是同一个人。
3. **处于什么阶段？** 问题出现、主动了解、比较选择、首次购买、使用、复购、放弃，对应不同证据。
4. **要找什么信号？** 生活语言、选择理由、实际行为、失败与替代，还是现象规模。

不要从“这个品类通常搜哪个平台”直接起步。先完成四问，再组合信源。

## 二、四类信源

### 1. 生活表达源

用于理解消费者如何讲述自己的处境、情绪、关系和日常动作。

常见来源：小红书、抖音、视频号、公众号、知乎生活问题、论坛帖子、社群公开讨论。

能回答：消费者怎样描述问题、用什么词、哪些细节难以被标准问卷捕捉。

不能单独回答：这种表达是否代表大多数人、表达是否等于真实行为。

### 2. 决策行为源

用于观察购买、不买、比较、使用、抱怨、退换、闲置和复购。

常见来源：电商评价与追评、商品问答、售后与退换讨论、对比帖、什么值得买、垂直评测社区。

优先级通常高于泛态度，因为它更接近付钱和使用的具体选择。

### 3. 圈层原生源

用于进入品类真实用户长期聚集和互相校正的地方。

常见来源随品类变化：虎扑、知乎、B站、什么值得买、汽车与硬件论坛、母婴社区、家装社区、兴趣群体公开内容。

圈层黑话、高参与讨论和老用户争论有价值，但资深用户不能自动代表普通购买者。

### 4. 宏观校验源

用于判断现象规模、方向和时间变化。

常见来源：政府统计、研究机构、上市公司数据、平台公开报告、行业协会、主流新闻。

宏观来源可以证明“发生了多少”，通常不能直接证明“消费者为什么这样做”。行业报告中的动机结论仍需回到原始行为与研究方法核对。

## 三、平台起始地图

以下只是提高权重的起点，不是永久固定权重。

| 研究对象或品类 | 优先观察 | 需要补的反面 |
|---|---|---|
| 年轻女性、美妆、母婴、生活方式 | 小红书正文与评论区、抖音、垂直社群、电商追评 | 未发帖者、使用失败、退货、不复购、价格与家庭决策 |
| 3C、男性兴趣、高参与决策 | 知乎、虎扑、什么值得买、B站、硬件论坛、电商问答与评价 | 参数党与普通用户差异、买前理由与长期使用、闲置和换机 |
| 家居、装修、耐用品 | 家装社区、公众号、视频号、知乎、电商评价、售后讨论 | 设计者与居住者差异、装修期与入住后差异、清洁维护成本 |
| 中老年与健康相关 | 视频号、公众号、社区表达、电商评价、公开问答 | 子女替父母购买与父母本人使用的差异；避免只听子女转述 |
| 食品、零食和即时消费 | 小红书/抖音场景表达、电商评价、外卖与到家平台公开内容、品类社区 | 第一次尝鲜与复购、吃不完、保鲜、价格、替代品和购买频率 |

遇到新平台或人群迁移时，以实际用户密度和行为接近度更新路线，不维护“所有品类都先搜小红书”的习惯。

## 四、评论区怎么读

正文常呈现一个经过整理的公开叙事；评论区更容易出现补充、反对、失败、例外和具体生活细节。评论区很重要，但不天然更真实。

优先记录：

- 带场景、动作、时间和替代方案的具体叙述；
- “我正好相反”“买过但后来不用了”等反例；
- 点赞不高却能解释一个决策细节的评论；
- 追问后暴露的真实限制，如价格、家庭成员、空间、时间和维护；
- 购买者与使用者对同一产品的冲突。

降低权重：

- 只复述博主观点；
- 纯情绪站队或玩梗；
- 无场景的“太真实了”；
- 明显营销账号、复制粘贴或高度同质表达；
- 用一个极端故事代表整个人群。

## 五、查询设计

同一问题至少包含三组查询，不机械追求平台数量。

### 正向表达

消费者怎样描述想要、喜欢、第一次购买和理想体验。

### 行为与代价

搜索具体动作与阻力，例如：怎么选、多久一次、谁买、谁用、放哪里、怎么保存、麻不麻烦、值不值。

### 反证与替代

主动加入：不买、踩雷、退货、吃不完、闲置、不复购、后悔、替代品、太麻烦、没必要、父母不用、孩子不吃等词。

反证不是为了否定洞察，而是找到它的适用边界和竞争解释。

## 六、跨信源对照

把证据按角色分开，不把它们混成“网上都这么说”。

| 证据角色 | 典型内容 | 主要用途 |
|---|---|---|
| 表达证据 | 帖子、访谈、评论、社群讨论 | 发现处境、语言与候选动机 |
| 行为证据 | 购买、追评、退换、复购、替代、闲置 | 检查人是否真的按自己说的做 |
| 规模证据 | 统计、销量、趋势、研究报告 | 判断现象有多大、是否持续 |
| 机制证据 | 对照、实验、长期追踪、业务数据 | 提高因果解释可信度 |

至少问：表达与行为是否一致？买前与买后是否一致？平台之间的冲突来自人群不同、阶段不同，还是解释本身有问题？

## 七、偏差检查

每次研究显式检查：

- **表达者偏差**：愿意公开表达的人和沉默用户不同；
- **算法偏差**：强情绪、完整故事和高互动内容更容易被看见；
- **幸存者偏差**：留下评价的人可能集中在极好或极差体验；
- **关键词偏差**：研究者带着 brief 搜索，容易只挑最像证据的内容；
- **角色偏差**：购买者替使用者说话；
- **阶段偏差**：尝鲜理由被误写成复购理由。

## 八、平台不可访问

登录、反爬、地区限制或评论不可见时：

1. 明确说明没有看到哪一类内容；
2. 换用同角色的替代信源，而不是随便换个平台；
3. 缩小结论边界，并降低可信度；
4. 若关键角色和反证都无法补足，停止在“现象”或“待验证假设”。

禁止用搜索摘要、二手转述或想象补齐未读取的正文与评论。
